# Local flag assets

These PNG files preserve the programme-card flag treatment without a runtime
request to a third-party host. They were downloaded from FlagCDN's public
country endpoints on 2026-09-06 and are based on the MIT-licensed
[`flag-icons`](https://github.com/lipis/flag-icons) project.

Files: China (`cn`), Czechia (`cz`), Greece (`gr`), Norway (`no`), Portugal
(`pt`), South Korea (`kr`), Türkiye (`tr`), United Kingdom (`gb`) and United
States (`us`). Simple geometric flags remain CSS gradients.
