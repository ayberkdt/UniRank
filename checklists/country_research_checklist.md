# Country Research Checklist

Use this checklist before starting a new country.

## Country Metadata

- [ ] Degree system identified
- [ ] Typical MSc duration checked
- [ ] Typical ECTS checked
- [ ] Non-EU application path checked
- [ ] Visa/pre-enrolment path checked
- [ ] Scholarship system checked
- [ ] Housing risk overview checked
- [ ] Common tuition structure checked
- [ ] Country-level sources logged

## Candidate Universities

- [ ] Initial university list created
- [ ] Official sources preferred
- [ ] Weak candidates separated
- [ ] Inactive programs excluded
- [ ] Programs grouped by relevance

## Country-Level Warnings

- [ ] Language risks documented
- [ ] Visa timeline risks documented
- [ ] Scholarship risks documented
- [ ] Housing risks documented
- [ ] Non-EU restrictions documented
