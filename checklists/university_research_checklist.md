# University Research Checklist

Use this checklist for every university-program record.

## Basic Program Verification

- [ ] Official program page found
- [ ] Program active
- [ ] Degree level verified
- [ ] Duration verified
- [ ] ECTS verified
- [ ] Teaching language verified

## Admission

- [ ] Admission page found
- [ ] Required background checked
- [ ] Non-EU eligibility checked
- [ ] Documents checked
- [ ] GPA/ECTS/test/interview requirements checked
- [ ] Admission risk assigned

## Cost

- [ ] Tuition page found
- [ ] Additional fees checked
- [ ] Non-EU fee checked
- [ ] Fee year recorded
- [ ] Cost confidence assigned

## Scholarship

- [ ] Scholarship page found
- [ ] Non-EU eligibility checked
- [ ] Deadline checked
- [ ] Housing/meal/cash grant checked if available
- [ ] Funding competitiveness assigned

## Curriculum

- [ ] Curriculum/study plan found
- [ ] Tracks/specializations checked
- [ ] Mandatory courses checked
- [ ] Elective courses checked
- [ ] Thesis/internship checked
- [ ] Category profile evidence added

## Research

- [ ] Department page checked
- [ ] Labs checked
- [ ] Research centers checked
- [ ] Relevant professors checked
- [ ] Projects checked

## Industry

- [ ] Official partnerships checked
- [ ] Nearby ecosystem separated from confirmed partnerships
- [ ] Internship/thesis possibility checked
- [ ] Career relevance noted

## Student Sentiment

- [ ] Forum/review search performed
- [ ] Sample size estimated
- [ ] Date range recorded
- [ ] Positive themes recorded
- [ ] Negative themes recorded
- [ ] Sentiment confidence assigned
- [ ] Sentiment not used as official fact

## Quality

- [ ] Source log complete
- [ ] Field confidence assigned
- [ ] Missing data marked
- [ ] JSON validates
- [ ] Canary tests passed
